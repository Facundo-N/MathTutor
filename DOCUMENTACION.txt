RESUMEN EJECUTIVO
=================

- Tutor inteligente de matemáticas (Banny)
- Chat en tiempo real con WebSocket
- Generación de problemas con OpenAI (GPT-4o-mini)
- Detección de problemas generados por IA vs legacy
- Base de datos SQLite para persistencia

QUICK START
===========
1. Backend:
   cd backend
   python -m pip install -r requirements.txt
   python main.py
   (Servidor en http://localhost:8000)

2. Flutter:
   flutter pub get
   flutter run
   (En Android emulador o dispositivo físico)

3. Usar Banny Chat:
   - Navegar a "Banny Chat" en la app
   - Escribir preguntas de matemáticas
   - WebSocket conecta a backend en tiempo real
   - OpenAI genera respuestas
