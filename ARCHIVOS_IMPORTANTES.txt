ARCHIVOS CRÍTICOS Y IMPORTANTES DEL PROYECTO
==============================================

FLUTTER (lib/)
==============
main.dart - Punto de entrada de la aplicación
lib/services/banny_chat_service.dart - Servicio WebSocket para chat
lib/services/openai_config.dart - Configuración de OpenAI
lib/screens/banny_chat_screen.dart - Pantalla de chat con Banny
lib/screens/new_home_screen.dart - Pantalla principal
lib/providers/ - Gestión de estado (Riverpod/Provider)
lib/models/ - Modelos de datos
lib/widgets/ - Componentes reutilizables UI

BACKEND (backend/)
==================
main.py - Servidor FastAPI principal
backend/api/websocket_routes.py - Endpoint WebSocket /ws/chat/{user_id}
backend/ai/problem_generator_ai.py - Integración con OpenAI (GPT-4o-mini)
backend/api/problem_routes.py - Endpoints para generación y detección
backend/database/database.py - Conexión a base de datos
backend/math_engine/generator.py - Generador de problemas
backend/math_engine/solver.py - Resolutor de ecuaciones (SymPy)
backend/.env - Variables de entorno (OPENAI_API_KEY)
backend/requirements.txt - Dependencias Python

TESTING
=======
backend/test_websocket.py - Test de WebSocket con OpenAI
backend/test_openai_setup.py - Verificación de API key

CONFIGURACIÓN
=============
pubspec.yaml - Dependencias Flutter
backend/requirements.txt - Paquetes Python
